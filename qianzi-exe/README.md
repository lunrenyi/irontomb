# 千字文：世界的源代码

> **QIANZI.EXE — DECODE AN ANCIENT WORLD MODEL**

把《千字文》讲的内容，用深空科学可视化、程序化世界生成与终端式交互重新做一遍。

- **影片**：一部约 195 秒的无声动态图形短片，七幕：解码 → 天地时序 → 山川草木 → 文字与制度 → 修身与人事 → 衣食器用 → 完整全景。
- **互动**：六个模块共用同一张世界地图，镜头在它们之间连续飞行；点原文句子看释义，点节点追关系。
- **视频导出**：`npm run export:mp4` → `out/qianzi-exe.mp4`。

画面里没有一张照片、一段视频或一张预制图片。
星场、二十八宿星图、节气盘、十二律管、山脉剖面、云雨霜晶、城郭宫室、
时间轴、人物、织机、琴、钓竿、一千个字的方阵与整张知识网络，
全部是运行时算出来的 SVG。

## 一眼看懂的分工

| 地方 | 干什么 |
|---|---|
| `src/content/qianzi.ts` | **文本真相来源**：全篇 250 句、逐句释义、释义视角、语义标签 |
| `src/content/modules.ts` | 六个模块的定义、区域坐标与读法限定 |
| `src/story/` | 影片时间轴：拍表、字幕、镜头、纯函数 `Film(frame)` |
| `src/viz/` | 画面：星场、知识网络、世界坐标、几何零件 |
| `src/components/` | 页面：开场、播放器、实验台、全景、原文索引 |
| `remotion/` | MP4 导出（与网页读同一份配置） |

**职责分离**：文字内容、场景时间线、视觉渲染、动画状态各在一层，互不越界。
场景组件只吃 `{ frame, beat, slot, progress }`，不读时钟、不读滚动、不用随机数 ——
所以同一帧永远得到同一画面，浏览器里播放的和导出成 MP4 的完全一致。

## 内容准确性：这一页最要紧的事

《千字文》最常被引用的一句评价是「一千个字不重复」。这句话需要加一个前提才成立：

> **原文用繁体字时，一千个字互不重复；换成今天的简体字之后，有七处被合并成了同一个字。**

| 简体 | 繁体原字（一） | 繁体原字（二） |
|---|---|---|
| 发 | 發（周武王姬发） | 髮（身体发肤） |
| 巨 | 巨（宝剑巨阙） | 鉅（鉅野澤） |
| 昆 | 崑（崑崙山） | 昆（昆明池） |
| 戚 | 慼（憂戚） | 戚（親戚） |
| 云 | 雲（雲氣） | 云（雲亭，山名） |
| 并 | 并（兼並） | 並（並皆佳妙） |
| 洁 | 絜（女慕貞絜） | 潔（紈扇圓潔） |

站里的「数字考古」模块把这个对比直接算出来给人看，
`src/content/qianzi.test.ts` 里也用程序验过：**繁体全文一千字、零重复**。

还有一组更少人提的差异 —— **避讳**：

| 通行本 | 传本异文 | 来由 |
|---|---|---|
| 天地玄黄 | 天地元黄 | 避宋太祖之祖赵玄朗名讳 |
| 周发殷汤 | 周发商汤 | 避宋太祖之父赵弘殷名讳 |
| 鸣凤在竹 | 鸣凤在树 | 一说为避宋英宗赵曙名讳 |
| 岳宗泰岱 | 岳宗恒岱 | 避宋真宗赵恒名讳 |

### 释义怎么标

每一句都带一个 `lens`（释义的读法），页面上始终标着：

- **古代宇宙观** —— 是古人的世界模型，不是已被现代科学证明的结论
- **历史叙述** —— 传说与信史分开标注
- **自然观察** —— 古人的经验归纳
- **伦理观念** —— 价值主张，不是事实陈述
- **现代科学解释** —— 单独一行，明确标为「今人对同一现象的解释」
- **制度与风物** —— 制度、器物、衣食住行

模块之间也各有读法限定（例如「历史」那一幕把传说画成虚线、信史画成实线，
「伦理」那一幕写明「这是伦理观念，不是行为科学」）。

**语义标签是本站的编辑标注**，不是《千字文》原有的结构。
知识网络（共享标签就连线）同样是本站生成的 —— 界面上这么写。

## 模块分配

250 句按原书顺序分进五个模块，第五个模块是全景（不收新句子）：

| 模块 | 句数 | 覆盖 |
|---|---|---|
| 01 COSMOS 天地时序 | 12 | 天地、日月、星辰、历法、时序 |
| 02 NATURE 山川草木 | 24 | 云雨、霜露、江河、地质、草木、飞禽 |
| 03 CIVILIZATION 文字与制度 | 80 | 文字、典籍、宫室、城市、礼制、律令、史事 |
| 04 HUMAN SYSTEMS 修身与人事 | 105 | 修身、孝悌、交友、家庭、心性、出处 |
| 05 DAILY LIFE 衣食器用 | 29 | 农事、饮食、纺织、器物、宴乐、起居 |

分模块的依据是原文本身，不为了凑模块名而改一个字的意思。
序章与全景可以跨模块引用 —— 那正是「关联」本身。

## 镜头

六个模块住在**同一套世界坐标**里，各占一块 1920 x 1080 的地方：

```
(0,-1680)  COSMOS ─── NATURE ─── CIVILIZATION
     │                                   │
(0,0) DECODE ─── DAILY ──────────── HUMAN
```

镜头在幕与幕之间是**飞过去**的，不是硬切：
起手 A（近）→ 拉远一次看清整张知识网络 → 落到 B（近）。
镜头只由固定取景与显式关键帧决定，**绝不追踪正在变化的图形** ——
否则画面会像在呼吸。单元测试逐帧检查镜头不跳变。

## 无障碍

- 遵循系统的「减少动态效果」：影片停在第一帧，可拖动进度条逐幕查看。
- 影片进度条是真正的 `role="slider"`，支持方向键 / Home / End。
- 原文索引是一排按钮，可键盘操作；释义卡片用真实标题层级。
