# 一条规则，长出无限

从一根枝条开始，看简单的规则如何创造复杂的世界。

- **影片**：一部 103 秒的声数学短片（种子 → 分叉 → 三种分支 → L-系统 → 自相似 → 路径之树）。
- **实验室**：按住「生长一代」，看 `F → F[+F]F[-F]` 一句规则怎么长出成百上千根枝条。
- **视频导出**：`npm run export:mp4` → `out/one-rule-infinite.mp4`。

画面里没有一张照片、一段视频或一张预制图片。
每一根枝条、每一片叶脉、每一条河流都是运行时算出来的 SVG 路径。

## 跑起来

```bash
npm install
npm run dev            # http://localhost:5174
npm test               # 32 个单测：L-系统 / 生长调度 / 叶脉 / 河流 / 镜头 / 几何
npm run build          # 类型检查 + 生产构建 -> dist/
```

## 导出 MP4

```bash
npm run export:mp4    # -> out/one-rule-infinite.mp4
npm run film:preview  # Remotion Studio，逐帧调时间轴
npm run film:still    # 导出一张静帧快速校对
```

实测输出：`h264 / yuv420p / 1920x1080 / 30fps / 3105 帧 / 103.5 秒 / 无音轨`。
首次执行会把 Chrome Headless Shell 下载到本项目自己的 `node_modules/.remotion/`。

规格集中在 `src/story/timeline.ts`（FPS、宽高、每个场景的起止帧），`remotion/Root.tsx` 直接读同一份配置。

## 影片时间轴

| # | 场景 | 起点 | 内容 |
|---|---|---|---|
| 1 | 一颗种子 | 0:00 | 一个几乎看不见的点，长出主干、分叉、再分叉；镜头贴着生长点走，再慢慢拉远 |
| 2 | 分叉 | 0:16 | 只看一根枝条长到末端长出两根新的；每一代把新长出来的部分点亮 |
| 3 | 三种分支 | 0:32 | 枝条 → 叶脉 → 河流，镜头连续过渡；同时讲清楚「像，但成因不同」 |
| 4 | 规则 | 0:50 | `F → F[+F]F[-F]` 逐字浮现，符号逐个解释，然后看着它作用在一根枝条上 |
| 5 | 从简单到复杂 | 1:08 | 一层层往上加，镜头一路后退；右上角开一个「局部放大」窗口对照自相似 |
| 6 | 路径之树 | 1:26 | 枝条变成带拐角的线路，节点亮起、光束跑向新末端，最后拉远 |

## 工程上的关键决定

- **一部影片，两个消费者。** `GrowthFilm({ frame })` 是纯函数：只接收帧号，
  不读时钟、不读滚动、不用定时器、不用 `Math.random()`。
  网站用 rAF 换算帧号喂给它，Remotion 用 `useCurrentFrame()` 喂给它 —— 两边是同一部片子。
- **确定性随机。** 树的自然抖动来自 `mulberry32(seed)`（`src/lib/rng.ts`）。
  同一个种子永远长出同一棵树，所以网页第 400 帧和 MP4 第 400 帧一模一样。
- **生成与绘制分离。** `lib/lsystem.ts` 只负责把规则变成枝条（纯数据、有单测），
  `viz/plant.tsx` 只负责把枝条画成 SVG，`story/` 只负责按帧取状态。
- **时间与代数对齐。** `lib/growth.ts` 按「每代的枝条数量」分配时间份额，
  并给出 `genEnd[g]`（第 g 代长完的那一刻）。实验室按它跳转，影片按它读数，
  所以「第 3 代」在实验室和影片里指的是同一棵树。
- **降级。** 跟随系统 `prefers-reduced-motion`：影片停在第一帧并提示可以逐章查看；
  实验室与其它章节照常可用，所有文字信息在关掉动画后仍然完整。

## 数学上刻意保持的准确

- 三种自然分支形态相似，但**生成机制不同**，页面与影片都写明了这一点：
  树是海龟按规则走的，叶脉是在一片有限的叶子里排布的，河流是一路向下游汇合的。
- 「无限」说的是规则可以继续迭代，**不是**有限时间内画出了无穷多个分支；
  影片与页面都明确说明屏幕上只有画出来的这几层。
- L-系统只是能生成植物样式的**简化规则**，不代表所有真实植物都这样生长。
- 末章的「路径之树」只是形态上的联想，页面上有一句话点明它不是比喻。

## 怎么打倒它

```bash
npm test                                   # 32 个单测
npm run film:still -- --frame=2400         # 换时间轴后先看这一帧
npm run export:mp4 && ffprobe out/one-rule-infinite.mp4
```

浏览器里：把分叉角拉到 41°，树的形态要真的变；把层数调到 5，枝条数要真的涨到 1024 根；
缩到 360px 宽，不允许出现横向滚动条；开「减少动态效果」，影片要停在第一帧并且还能逐章看。

## 遗留问题

- 手机竖屏下 16:9 的字幕偏小，页面已提示横屏或全屏；根治需要单独一版竖屏 Composition。
- 教学规则每代是上一代的 4 倍，第 5 代就 1024 根枝条，再往上浏览器吃不消，实验室因此封顶在 5 代。
- 叶片布局仍是「每根末梢枝条上放 3 片」，没有做叶序（phyllotaxis）级别的排布。
