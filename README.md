## 新东西进来的规矩

一个子项目要满足：

- **跑得起来** —— 附上跑它的命令。没跑过的东西不算数。
- **小到能被完整读完** —— 宁可十个小的，不要一个说不清内部结构的大东西。
- **自带上下文** —— 动机、做法、结论、遗留问题都在这个目录里，
  三个月后回来不用去翻对话记录。
- **能被打倒** —— 结论要能被复现，也要能被证伪。写清楚怎么打倒它。
- **诚实** —— 跑不通就说跑不通。装饰性的完成度是牢笼的一部分。

产品、作品集、半成品的框架、没人运行过的设计文档。
