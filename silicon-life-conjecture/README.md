# 硅基生命的猜想 · Silicon Life Conjecture

一部可以动手操作的互动科学展览。
从宇宙中的 0 和 1 出发，看简单规则如何产生复杂行为，理解神经网络与计算机系统，
再讨论人工智能、意识与未来生命的可能性。

**所有主要画面都是程序实时算出来的**，没有使用任何实景照片、实景视频或预制素材。

### 节奏与字幕是怎么定下来的

时间轴只有一份配置：`src/story/score.ts`。每一幕是一串「拍」，每拍写三件事：

- `min`：这一拍画面自己至少要多久；
- `cues`：这一拍的底部字幕（可多句，按语义拆开）；
- `key`：这一拍中央出现的那一句关键文字（可指定纵向位置 `y`）。

一拍的实际长度 = max(min, 这一拍的字幕读完需要的秒数, 中央关键文字读完需要的秒数)。
字幕停留时间由**字数、行数与字号**算出来（`src/story/layout.ts` 的 `readingFrames`），
所以改长一句话，它所在的那一拍会自动变长 —— 字幕永远不会被画面切断。

字幕带的高度也是算出来的（最大行数 x 字号 x 行高），不是拍脑袋定的固定高度，
主视觉区、关键概念区、底部字幕区三块互不重叠。任何一条字幕排不下、
两条字幕撞在一起、某一拍被字幕撑爆，都会在 `npm test` 里报出来。

### 三块纵向分区与转场

每一幕的画面按**纵向三块**排布，互不遮挡（第四幕的数值在 `src/story/layout.ts`）：

1. **主视觉区** —— 正在动的那个对象；
2. **关键概念区** —— 章节里那一句话/公式，不是旁白字幕；
3. **底部字幕区** —— 完整解释句。

幕与幕之间用**压黑转场**（dip-to-black）：旧画面先淡到黑、黑场里新画面再淡入。
所以任一时刻最多只有一个幕的文字在画面上，不会出现两幕文字交叠。
第五幕内部的每一拍之间也用同样的压黑转场 —— 那一幕每一拍都有密排的文字，
交叉溶解必然撞车。

`npm test` 里有一条回归测试（`src/story/timeline.test.ts`）专门盯着第四幕：
断言关键文字底边 < 阶段条顶边、阶段条文字 < 主视觉顶边、主视觉底边不侵入字幕带，
并且所有第四幕关键文字都落在 `COMPUTER_KEY_Y` 这一行上。

## 这些画面是真算出来的，不是播动画

这一站的核心原则：**每一个视觉元素背后都有一个确定性模型，网页与 MP4 共用同一份实现。**

| 模型 | 文件 | 做了什么 |
| --- | --- | --- |
| 康威生命游戏 B3/S23 | `src/lib/life.ts` | 同步推进一代；方块静止、闪灯周期 2、脉冲星周期 3、滑翔机每 4 代平移一格、滑翔机枪每 30 代发射一个滑翔机，全部由测试验证 |
| 微型计算机 | `src/lib/vm.ts` | 一台真的能跑指令的机器：两遍汇编器、五个微阶段（取指 / 译码 / 执行 / 写回 / 输出）、寄存器 / 内存 / ALU / 控制信号；五段程序输出 42、55、1010、SILICON、类别 0 |
| 漏电整合发放神经元 | `src/lib/neuron.ts` | 连续的膜电位、阈值、不应期、衰减的突触电流；画面上那条起伏曲线是模型算出来的轨迹 |
| 逻辑电路 | `src/lib/circuit.ts` | 完整真值表、半加器、全加器、四位行波进位加法器（对全部 256 种输入验算过），以及把连续电压切成 0 / 未定义 / 1 的电压轨 |
| 小语言模型 | `src/lib/tinymodel.ts` | 真的前向传播 + 真的反向传播（交叉熵 + 全批量梯度下降），词表 9 个词、嵌入 4 维、隐藏层 12 个神经元；训练把损失从 2.27 降到 0.01 |
| 大模型原理示意 | `src/lib/llm.ts` | 最长匹配分词（切分后能原样拼回）、确定性词向量、注意力矩阵（每行真跑一遍 softmax，行和正好为 1）、逐步生成的候选分布、温度与解码策略。**画面上没有接入任何真实大模型**，这些是确定性教学数据，只有训练那条损失曲线是真的 |
| 进化模拟 | `src/lib/evolve.ts` | 真的遗传算法：选择、交叉、变异，第 22 代环境换一次目标，可以看着适应度掉下去再爬回来 |
| 采样与量化 | `src/lib/signal.ts` | 波形采样、量化、二值化、比特翻回字符 |
| 碳与硅 | `src/lib/atoms.ts` | 真实数据：原子序数、电子排布、键长 154 vs 235 pm、键能 348 vs 226 kJ/mol；CH4 / SiH4 / CO2 / SiO2 的结构 |

`npm test` 里有 102 个测试，覆盖上面每一项的性质（比如「四位加法器在全部 256 种输入下等于真正的加法」、
「分词切完能原样拼回原文」、「注意力每一行加起来正好是 1」、「训练损失真的降下来了」）。

### 确定性

整站不使用 `Math.random()`。随机性一律来自 `src/lib/rng.ts` 的固定种子随机数，
时间一律来自「帧号」，所以**同一帧永远得到同一画面**：Remotion 渲染出的 MP4 与浏览器里看到的完全一致。

## 科学表述上的几条红线

这些限制不是免责声明，而是内容设计的一部分，页面上每幕末尾都有一个可展开的「科学说明」：

1. 0 和 1 是对连续物理量的一种**数字化约定**，不是世界的性质；电压中间存在「未定义」区。
2. 生命游戏里的「存活」是数学状态。没有代谢、没有意识、不会真的繁殖。
3. 神经元与晶体管只在**系统层面**可比；物理机制与功能结构有重大区别。人工神经网络不是大脑的复制品。
4. 计算机能运行复杂程序，不等于程序足够复杂就必然产生意识。硬件架构、程序、算法、训练过程与运行时机制是五件事。
5. 智能、自我表征、主观体验、灵魂是四个不同的概念。第五幕的判断实验**刻意不给对错**，只说清每条证据支持到哪一步结论。
6. 硅基化学生命与「跑在硅芯片上的人工系统」被明确分开：前者是假想的化学骨架，后者是今天真实存在的半导体技术。
7. 碳和硅**不是可以一比一互换的元素**。相似（同族、同价电子数、同样的正四面体）是真实的；差别（键长、键能、二氧化硅没有独立分子）同样真实。
8. 硅基生命目前属于推测性讨论。生命的一种常见工作定义是「能够维持自身、并进行达尔文式进化的化学系统」，但定义本身仍在讨论。

### 浏览器进程纪律

`AGENTS.md` 要求：QA 只允许一个 headless 浏览器。本项目照做：

```bash
./scripts/browser-guard.sh ensure   # 幂等：已有就复用
./scripts/browser-guard.sh status   # 只看现状
./scripts/browser-guard.sh stop     # 一轮 QA 结束必须调用
```

抽帧请用 ffmpeg 对成片抽帧，不要循环跑 `remotion still`（那会反复拉起浏览器）：

```bash
ffmpeg -i out/silicon-life-conjecture.mp4 -vf "select='not(mod(n\,300))',scale=560:-1,tile=4x4" -frames:v 1 -y qa/mp4/contact-sheet.png
```

### 文字重叠检查（QA）

只靠肉眼看整片会漏掉几十帧里才出现一次的重叠，所以有两个脚本直接量真实 DOM：

```bash
# 扫指定帧段里每一对文字框的重叠（阈值：较小框面积的 12%），并报出界的文字
SLC_SETTLE=100 node qa/collide.mjs 4215 6280 13

# 找 <svg> 里的 <StageLabel> 之类被塞成 0x0 的死标签
node qa/labelprobe.mjs
```

两者都通过 `browser-guard.sh` 复用同一个 headless 浏览器，不新开进程。
